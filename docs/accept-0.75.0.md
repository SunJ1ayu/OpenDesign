# 真机验收清单 —— 0.73.0 / 0.74.0 / 0.75.0(三版一起装)

> 给机主的一页。**每条都是「你做什么动作 → 该看到什么」**,看到了就打勾,
> 对不上就把看到的原样告诉我(别替我解释原因,原话最有用)。
>
> 这三版里有两件事**光看界面看不出来**(日期算得对不对、断线能不能自愈),
> 所以必须动手制造那个场景 —— 这份清单存在的唯一理由就是这个。

## 0. 装之前(两句话)

- 更新步骤见 `docs/install-windows.md`;**这次必须重跑一次装机脚本**
  (0.72.0 换了 MCP 入口,那个路径写在 `%USERPROFILE%\.nanobot\config.json` 里,
  `git pull` 改不到它)。
- 起服务时要在输出里看到 **「已同步助手契约」** —— 0.73/0.74 改的大半是助手的行为规则,
  不同步这一下等于没更新。

**先对版本**:浏览器 `Ctrl+F5`,然后

```powershell
(irm http://127.0.0.1:8766/api/health).version
```

**要显示 `0.75.0`**。不是就别往下走。

## A. 断线自愈(0.75.0 —— 本批最值得验的)

> 这一组必须**主动制造断线**。三种做法任选,推荐第 1 种(最贴近你真实会遇到的)。

### A1 停掉 gateway 再起(最像"gateway 崩了")

1. 打开工作台,随便和助手说一句,等它回完。
2. **不要关浏览器**,另开一个 PowerShell:
   ```powershell
   powershell -ExecutionPolicy Bypass -File D:\AI\OpenDesign\bin\start.ps1 stop
   ```
3. 回到浏览器看聊天那一栏。
   - [ ] **该看到**:顶部一条细的「**正在重连…**」,而**下面之前聊的内容还在**。
   - [ ] **不该看到**:「连接已断开」+ 要你点的「重试」按钮;也不该整个清空变成「正在连接聊天服务…」。
4. 把服务起回来:
   ```powershell
   powershell -ExecutionPolicy Bypass -File D:\AI\OpenDesign\bin\start.ps1
   ```
   - [ ] **该看到**:**不用你点任何东西**,过几秒它自己回到「已连接」。
5. **最关键的一步**:连回来之后**再发一条消息**。
   - [ ] **该看到**:发得出去、助手正常回复。
   - [ ] **不该看到**:能打字但发送键是灰的、点不动。
   > 这一条单列,是因为上一版真的坏在这里(重连成功了但聊天被锁死,只能刷新页面),
   > 是评审抓出来的,不是我测出来的。

### A2 项目列也要验一遍(**别只在首页验**)

进**某个项目**的助手那一栏,重复 A1 的第 2–5 步。

- [ ] 项目列断线时**也**是「正在重连…」+ 对话留在眼前,不是清屏。
> 单列它同样是因为上一版就坏在这:自愈只在首页生效,项目列——你平时干活的地方——没生效。

### A3 合上笔记本(可选,最贴近日常)

合盖几分钟再打开。
- [ ] 该看到:回到前台后**很快**自己连上(不用等十几秒,更不用手点)。

### A4 断线期间漏掉的内容(可选,要点耐心)

1. 和助手说一句会让它想比较久的话(比如「把这个项目的变更都汇总一下」)。
2. **它还在打字的时候**把 gateway 停掉,过 10 秒再起回来。
   - [ ] 该看到:重连之后,那条回复**是完整的**(从服务端重新拉回来的)。
   - [ ] 不该看到:一条半截的、一直在转圈的回复;或者同一段话出现两遍。

## B. 助手在干什么(0.75.0)

1. 问一句「有什么待办」。
   - [ ] 该看到:它去查的时候界面有动静(三个点),查完**多一行灰字**,
         类似「**查了待办清单**」。
   - [ ] **不该看到**:`mcp_design-studio_list_todos_tool` 这种一串英文下划线的东西。
2. 让它给你一个网址(比如「打开原版界面那个地址」),点一下。
   - [ ] 该看到:**新开一个标签页**,工作台这一页还在(不会被顶掉、不用重连)。

## C. 日期由代码算(0.74.0 —— 光看界面看不出来,必须核对)

1. 对助手说:「**提醒我下周三交初稿**」。
2. 去项目档案里看它记的那条,**核对日期对不对**。
   - [ ] 该看到:算出来的就是真正的下周三。
   - [ ] 不该看到:差一天、差一周、或者是个过去的日期。
3. 再说一句用**确切日期**的:「**8 月 20 号要交效果图**」。
   - [ ] 该看到:记的就是 8 月 20 日,不多不少。

> ⚠️ **这条依赖机器时钟**:代码是拿这台电脑的"今天"往后推的。
> 如果你发现算出来的日期整体偏了一天,**先看看电脑右下角的日期对不对**,
> 别急着当成 bug —— 但**看到了就告诉我**,这台 Linux 机上我已经发现时钟对不上。

## D. 记事时带上下文(0.73.0)

1. 说一句带截止日的事项(上面 C 已经做过就不用重复)。
   - [ ] 该看到:它记下来的时候**带上了是"从哪天算起"**,不是光一个孤零零的日期。
2. 对一个**已经有旧事项**的项目再提一件冲突的事(比如同一处又改一次)。
   - [ ] 该看到:它会**提醒你和之前那条有冲突**,而不是闷头再记一条。

## 出问题怎么给我反馈(比"坏了"有用一百倍)

按这三样给我,我基本就能定位:

1. **你做的动作**(第几条、点了什么);
2. **你看到的原话/原样**(截图最好,文字照抄也行 —— **别帮我概括**);
3. 如果是连不上类的,把这个文件的最后 30 行发我:
   `%USERPROFILE%\.openDesign\logs\gateway.log`

**特别的**:A 组任何一条对不上,先别继续往下验 —— 那说明自愈这单没生效,
后面的现象都可能是它派生出来的。
