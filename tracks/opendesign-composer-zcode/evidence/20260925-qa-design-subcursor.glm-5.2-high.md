## 1. 用户故事 + 验收标准(Given / When / Then)

**US1 用「+」菜单选图片**
- Given 首页聊天输入卡可见,「+」按钮可点
- When 用户点「+」,再点第一项「图片」
- Then 弹出系统选图框;选好后缩略图出现在输入卡内;菜单项旁能看到「也可拖进来 / Ctrl+V」字样

**US2 用「+」菜单或「/」选技能并补开头**
- Given 输入框可编辑(不在回复中)
- When 用户点「+」→ 某技能,或在输入框打 `/` 后选某技能
- Then 输入框内容前缀变成该技能开头(记一下 → `记一下:`;整理文件夹 → `帮我扫描整理这个文件夹:`;找参考图 → `找参考图:`),光标停在前缀后;若原本有字,原字保留在前缀之后;若原本已是某技能开头,则替换为新开头而不叠加;「✎ 记一下」按钮已不存在

**US3 输入框打 / 弹技能表并按字筛**
- Given 输入框为空或光标在行首,不在回复中
- When 用户以 `/` 开头且其后无空格
- Then 弹出技能表;继续打字按字筛选(如 `/参考` 只剩「找参考图」);↑↓ 选中、Enter 或 Tab 应用;Esc 关闭;筛空时不弹且 Enter 把整句(含 `/`)发出;占位字为「聊设计、找参考;输入 / 选技能」

**US4 看到模型按钮带厂商名**
- Given 当前选中某厂商某模型
- When 用户看输入卡右下模型按钮
- Then 按钮显示「厂商短名 · 模型名」,短名 = 设置页该家名字去掉括号部分(MiMo(小米)→`MiMo`;GLM 套餐(Coding Plan)→`GLM 套餐`;自起名照写);换厂商/模型后按钮文字随之更新

**US5 在回复中点停止**
- Given 助手正在回复(「正在思考」或正在出字)
- When 用户点 ■ 停止
- Then 本次回复立即停下;已出的半截回答留在气泡里;该气泡下出现灰色小字「已停止」;不会出现写 `/stop` 的气泡;输入框解锁、发送键回到 ↑;切走再回来、关掉重开,看到的仍是中文「已停止」

**US6 看到按时间的问候语**
- Given 首页无对话(空状态)
- When 用户在不同时段打开首页
- Then 大字问候为「早上好 / 中午好 / 下午好 / 晚上好 / 夜深了」之一,后接「,今天想聊点什么?」

**US7 看到中文的错误说明与系统消息**
- Given 助手回复出错或后台有系统消息
- When 错误为厂商原话时,小字标「原文:…」;错误为后台改写过的固定英文时,小字改标别的说法(不叫「原文」)
- Then 系统消息(如 `Stopped 1 task(s).`、`No active task to stop.`、`Background task completed.`)以中文出现在聊天里,不出现英文原样

## 3. 探索式测试任务(拿真界面试)

1. **停止键全时机巡检**:目标——找出停止后状态不自洽的瞬间。重点:刚发出还在「正在思考」、出字到一半、接近说完、说完的一瞬、出错气泡刚出现;每次停后查「气泡内容 / 已停止灰字 / 按钮形态 / 输入框可编辑性 / 再发一次是否正常 / 切走再回是否一致」六处。
2. **草稿 × 技能补开头矩阵**:目标——找出补/换开头时丢字、叠头、丢图、光标位置错。重点:空草稿、纯文字草稿、已是同技能开头、已是别技能开头、含 1~4 张图、含换行、含未选拼音 七种前置 × 三种技能入口(+菜单 / / 菜单 / 技能页)。
3. **三栏并发只停一栏**:目标——确认停止只作用于当前栏,不串扰。重点:三栏同时回复中,分别停每一栏,另两栏继续且各自后续仍能停;停过的栏再发新消息正常。
4. **IME × 斜杠菜单**:目标——确认中文输入法下 `/` 触发与选字互不打架。重点:拼音候选框打开时打 `/`、`/` 后接拼音、技能表弹时按 Enter 是「选技能」还是「选字」、Esc 关表是否连候选框一起关。
5. **错误说明文案与系统消息中文化**:目标——确认 a/b 两条在真实错误下落地。重点:故意触发欠费类(后台改写)与厂商原话类两种错误,核对小字标签;触发停止无任务、后台任务完成等,核对中文且无英文残留;翻历史对话看旧英文是否回填。

## 4. 需要产品负责人拍板的疑问
