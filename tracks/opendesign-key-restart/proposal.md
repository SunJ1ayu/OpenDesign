# Proposal: opendesign-key-restart

- Date: 2026-09-25
- Status: open

## Goal

设置页存完 key 之后,聊天照常能用、输入框的换模型按钮照常在 —— 不用退出重开。

## Motivation

0.98.12 的主路坏了:业主 09-25 真机每存一次 key,聊天就一直「连接不上,gateway 可能没在跑」,换模型按钮跟着消失(它只在连上时显示),只能托盘退出重开。

## 真问题(第一性)

- 用户原话:「我切换模型填入api key之后 新对话一直显示链接不上gateway」「重启之后可以了」「但是我换模型列表没有可以点击的地方，只有一个测试一个编辑。。你让我怎么换模型呢，聊天列表只要我填一次apikey之后就一直显示连接不上gateway 然后输入框右下角没有模型选择框了」「zcode是怎么做到切换模型直接能用的」
- 真正要解决的是:填完 key 就能接着聊、接着换模型;ZCode 是存了就能用(运行中的进程每 1s 重读个人 provider 配置),我们是存 key ⇒ 重启网关,而这条重启链在两个系统上都会断。
- 我在这中间翻译了什么:把「换模型没地方点」归到同一个根(按钮只在连上时显示),不是设置页少了按钮 —— 修好连接后要真机确认按钮回来了、能换。
- 用户可观察的成功:在聊天页连着的情况下存任意一家的 key,不退出软件,聊天自己恢复、右下角换模型按钮在、能换到新厂商并收到回复。

## Scope

- in: 查清 Windows 上新网关为什么起不来(探针 windows-restart-probe);修重启链,或改成不需要重启(方案先过 4c)。
