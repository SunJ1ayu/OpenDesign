## 事实核查:GitHub 发布资产的 Range 支持(2026-09-22 主 agent 亲跑 curl)

- 单段 \`-r 0-99\` → 302 到 release-assets.githubusercontent.com → **206**,\`content-range: bytes 0-99/46799268\`
- 多段 \`-r 0-99,1000-1099\` → 302 → **501**
- \`/releases/latest/download/…\` → **404**(本仓 25 个 release 全是 prerelease,「最新正式版」不存在)

⇒ 增量更新走 GitHub 必须 \`useMultipleRangeRequest:false\`(一段一段要);「最新版」固定地址要求 Electron 版按正式 release 发。
