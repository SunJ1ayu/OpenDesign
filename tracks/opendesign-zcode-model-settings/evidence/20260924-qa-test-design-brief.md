## 现在的样子(要被替换的)
- 侧栏「设置」点开是一个小弹层(AI 模型、工作区文件夹、危险动作确认、快捷键、软件更新)。

## 要做成的样子(照 ZCode;截图见 https://doc.dmxapi.cn/zcode.html 里「模型设置」几张)
- 点「设置」进入**整页设置**:整个侧栏换成设置栏目(返回工作区 / 常规 / 模型设置)。「常规」放原来弹层里那些(含软件更新)。
- 「模型设置」页:标题 + 说明 + 刷新 + 添加供应商;下面一张大卡片 ——
  左栏:厂商列表,分「内置供应商」(五家)与「自定义供应商」+「添加供应商」;每行图标 + 名字 + 状态小圆点(能用 / 没配好 / 已禁用);
  右边:选中这家的详情 —— 名字 + 已启用/禁用、Base URL(内置的只读)、API Key(可显示/隐藏)+「获取 API Key」链接、
  **模型列表**(每行:模型名、上下文长度、测试 / 编辑 / 删除;内置模型不能删)+「添加模型」(弹窗填模型 ID、上下文窗口)。
- 「添加供应商」(自定义):名称、Base URL、API Key、API 格式(只支持 OpenAI 兼容 Chat Completions)、至少一个模型。
- 聊天框换模型弹框:每家一行(当前那家打勾),移上去向右弹出这家的模型(当前模型打勾),最底一行「管理模型」直达设置页这家。

## 已定的规矩(产品负责人与开发已确认)
- 存 key **不会**换掉你当前正在用的模型;要换模型在聊天框里选。
- 正在用的那家**不能禁用**、正在用的模型**不能删**(要先换别的)。禁用 = 这家从换模型菜单里消失,key 保留。
- 只有已经填了 key 的厂商会出现在换模型菜单里;新填的 key 保存后软件会自动重启后台让它生效(几秒)。
- 老装法(不是 Windows 安装包,而是开发者用源码跑的)只能用一家,加不了自定义供应商。
- key 在界面上永远只显示首尾几位,不显示原文。
