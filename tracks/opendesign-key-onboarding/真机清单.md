# 真机清单:在界面里填大模型 key

**在 Windows 机器上做,一条一条来。**每条只要回我「第 N 条 OK」或者把看到的东西
描述一下就行 —— 不用截图,除非那一条特别写了要截图。

> 为什么还要你跑:下面这些,我在 Linux 上**验不了**。不是没写判据,是那台机器上
> 根本没有 Windows 的文件权限语义、没有桌面外壳、也没有真的模型在回话。

---

## 一、第一次打开(装完还没填 key 的样子)

1. **装完直接打开,应该自动弹出一张让你填 key 的卡片。**
   - 卡片里有:选厂商的下拉、填 key 的输入框、保存按钮
   - 输入框里打字应该显示成圆点(不是明文)

2. **点卡片外面的空白处,卡片要能关掉。**关掉之后界面能正常点(不是点哪都没反应)。

3. **关掉之后,把程序关了重开 —— 那张卡片应该还会再弹。**
   (不能"关过一次就再也不提醒"，否则你永远填不上。)

4. 🔴 **关掉卡片,进到任意一个项目的工作区,看右边那条聊天栏。**
   - 它应该显示 **「未连接聊天服务」** 这样的提示(琥珀色横幅),点它能打开连接卡
   - **不应该**一直转圈显示「正在连接聊天服务…」
   - 这一条是这次修的最重要的 bug,请特别看一眼

## 二、真的填一次 key

5. **在卡片里选一个厂商、粘贴你的 key、点保存。**
   - 保存后应该给你一句提示,告诉你**要重启程序**(或者它自己重启)
   - 输入框应该被清空,**不该**把你刚填的 key 再显示出来

6. **按提示重启程序,然后试着聊一句天。**
   - 🔴 这是**只有你能验**的一条:模型真的回话了吗?
   - 全程**不应该**再要你输入任何"口令"

7. **再打开一次那张卡片(左下角设置 → AI 模型)。**
   - 它应该显示 **只有末尾四位** 的样子(比如 `sk-a…9f3c`),**不该**显示完整的 key
   - 这次**不应该**自动弹出来了(因为已经配好了)

## 三、换一把 key

8. **在设置里再填一把不同的 key,保存、重启、再聊一句。**
   - 应该用的是**新的**那把(如果模型报错说 key 无效,那说明换成功了但 key 本身不对)

## 四、如果你这台机器设过环境变量(多半没设,没设就跳过 9)

9. **如果你的 Windows 里设过一个叫 `DS_LLM_KEY` 的环境变量**:
   - 打开那张卡片,输入框应该是**灰的、填不了字**
   - 并且有一句话告诉你:key 是由环境变量提供的,在这儿改不生效
   - (没设过就跳过这条 —— 大多数情况你没设过)

---

## 我这边**没法**替你验的,列清楚免得你以为验过了

- **key.txt 的文件权限**:Windows 上是 ACL 语义,和 Linux 完全不同。
  **本单不声称"别人读不到这个文件"** —— 只声称我们自己不到处乱写它。
- **重启之后真的能聊天**:判据只能验"发出了重启请求",发出去之后的事只有真机知道。
- **真的模型在回话**:开发机全程用的是假 key,一次真调用都没发生过。
