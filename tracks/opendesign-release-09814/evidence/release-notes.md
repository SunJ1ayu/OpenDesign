# OpenDesign 0.98.14

这版把聊天输入和历史对话补齐了。

- **聊天出错会显示说明**:遇到 API Key 不对、额度不足、限流或超时,聊天里会给出提示,不再只留一个空白。识别不出的错误会保留已打码的详情。
- **输入框「+」有菜单**:可以添加图片,或选「记一下 / 整理文件夹 / 找参考图」,帮你填好开头。输入 `/` 也能选这三个技能。
- **回复时可以停止**:平时按钮写「发送」,回复中变成「■」。模型按钮会带厂商名;空白聊天页的问候语按时间变化。
- **历史对话能翻全**:侧栏「按时间」分今天、昨天、更早,点「显示更多」继续翻;每条对话的「⋯」可以置顶、改名、删除。置顶和自定名字关掉重开仍保留。
- **可以「按项目」看对话**:点项目旁带对话图标的数字展开,点一条接着聊。助手实际操作过几个项目的对话会出现在对应项目下;只在文字里提到项目、没有操作的对话放在「其他对话」。两种视图会记住上次选择。

已知限制:项目反复改名、重名后,少数旧对话的项目归属可能不准;「按时间」仍能找到。该问题尚未修好。

## 升级

已经装了 Electron 版(0.98.9 或更新):打开软件,在「设置 → 常规 → 软件更新」检查更新。下载完成后点「重启以更新」,跟随安装向导。
手动安装只需要下载 `OpenDesign-0.98.14-electron-setup.exe`,无需先卸载旧版。`.blockmap` 和 `latest.yml` 给自动更新用。
安装后在「设置 → 常规」确认当前版本为 `v0.98.14`。
