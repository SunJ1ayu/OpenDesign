# 真机清单 —— 把系统窗口框架接回来

装完照着点一遍,**大概八分钟**。红了的把编号发我。

> 这一版改的是**外壳**(窗口本身)⇒ 光 git pull 不够,**要重装安装包**。
>
> ⚠️ **这一版比 0.92 危险。** 0.92 只贴了三个不参与绘制的样式位,承诺"外观零变化";
> 这一版**动了窗口的边框计算**。所以 C 组(外观)才是重点,不是 B 组。

---

## A. 先确认装对了(不过这两条,后面全不作数)

- [ ] **A1** 打开软件 → 打开日志文件 `%LOCALAPPDATA%\OpenDesign\Logs\外壳.log`,
      找最后一次启动那段里有没有这一行:
      ```
      [窗口] 已接管非客户区(WM_NCCALCSIZE)
      ```
      **有 = 新外壳真的在跑。没有 = 停,别往下走,把日志发我。**

      > 🔴 上一版这条闸我写错了:当时让你查 `/api/health` 的 version ——
      > 那是**网页后端**的版本号,`ds_shell.py`(外壳)**根本没有自己的版本号**,
      > 所以那条问不出外壳新不新。这次改成让**外壳自己开口**。

- [ ] **A2** 打开记事本点它的最小化 —— 记事本有没有"收进任务栏"的动画?
      没有 ⇒ 是系统的动画总开关关了,**任何**程序都没有,我改什么都白改。
      (你上次说别的软件都有,大概率直接过。)
