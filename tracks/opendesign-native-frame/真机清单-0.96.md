# 真机清单 —— 0.96.0(动画默认开着)

**装完直接用,不用再建任何文件。** 大概两分钟。

## A. 先看这一条

- [ ] **A0** 打开软件,**界面出来了吗?**(一片白就停,告诉我)

## B. 你要的那个东西

- [ ] **B1** **点右上角的缩小按钮。窗口有没有向下收进任务栏的动画?**
      —— 这就是你从 0.92 起问了四个版本的那件事。
- [ ] **B2** 从任务栏点回来,有没有展开回来的动画?
- [ ] **B3** 点中间那个最大化按钮,有没有放大的动画?任务栏还看得见吗?
- [ ] **B4** 再点一次,收回去了吗?

## C. 万一还是坏的

- [ ] **C1** 如果点了缩小之后**画面白了/花了**:先**重开软件**——
      这一版开窗口时什么都不做,所以重开一定是好的。
- [ ] **C2** 然后在 `%LOCALAPPDATA%\OpenDesign` 里建个空文件叫
      `关掉窗口动画.on`,重开 —— 从此不再试,窗口回到 0.94 那样稳。
- [ ] **C3** 把 `Logs\外壳.log` 最后 50 行贴我(`[诊断]` 那几行是关键)。

## 这一版为什么可能真的不一样

前三版失败我一直归到"时机"上,是你追问「别人做成了为什么我们做不成」
才逼我去读参考实现的源码。结果发现:**我们和唯一一个同栈成功实现(WinFormedge)
在一个具体的地方不一样** —— 处理某条窗口消息时,它交回系统默认处理,
而我们自己截断了。而那个偏离,恰恰是 0.93(你唯一跑过、然后白屏的那版)才引入的。

⚠️ 仍然只是**最可疑的线索**,不是已证实的根因。真机说了算。
