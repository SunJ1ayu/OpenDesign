# Proposal: OpenDesign 0.98.10 发布(正式 release `v0.98.10`)

- Date: 2026-09-23
- 业主原话:「发 我是不是打开软件可以自动检测」;随后「我已经装了0/98.8」,紧接着更正「不对 我装了0.98.9说错了」⇒ **业主机器是 0.98.9(Electron)**。
- 发的内容:已归档 PASS 的 `opendesign-instant-ui`(冷启动窗口一出来就是工作台 + 窄窗不再横向滚动 + 管家意外退出弹框并退出)。
  业主已装 v0.98.9 ⇒ 0.98.10 走**应用内自动更新**(这是 Electron 更新器在生产上的第一次真走)。

## 本单做什么

1. 版本号 0.98.9 → 0.98.10(`bin/ds_web.py VERSION`、`desktop/package.json`;只加第三位)。
2. 先还上一张发版单的延期 #1:`installer/RELEASE.md` 第 1 步「E1～E6 必须通过」→「E1～E7 全过」(artifact 在 E7 之前上传,照旧文档可能取到没过 E7 的包)。
3. 云 Windows 整跑 FAIL 0,从同一次运行取出货三样;两家族评审;推送 main;发布正式 release;发布后生产源 smoke
   (`releases/latest/download/latest.yml` 指向 v0.98.10、安装包/blockmap 字节 = artifact)。
4. 业主在 0.98.9 里等「重启以更新」出现 → 点 → 向导两下 ⇒ 真机回显 0.98.10 + instant-ui 移交的真机清单(同时接上 0989 单的真机 A0)。

## 验收边界与轮次预算

- 承诺:发出去的安装包来自云上测过的同一次运行、与被测版只差更新源;release 为正式版、三样资产;生产源 latest 指向 0.98.10 且字节一致;
  已装 0.98.9 的机器能从生产源看到 0.98.10(清单版本号 + 旧 blockmap 路径 `download/v0.98.9/` 存在);
  业主真机:版本 0.98.10、冷启动第一眼是工作台(有 key 时横幅在、各页只转圈不报错、好了自己出来)、窗口拖窄首页无横向滚动。
- 承诺(追加):业主 0.98.9 经生产源自动更新到 0.98.10(真机回显)。
- 发版说明:从 0.98.9 升上来会重置三项本机偏好一次(项目对话映射 / 图库列数 / 侧栏折叠),写明;从 0.98.8 手动装的人不受影响。
- 实质评审上限:2 轮(impact=high:公开发布 = production_side_effect)。每轮派发前先跑 `track preflight opendesign-release-09810`。
