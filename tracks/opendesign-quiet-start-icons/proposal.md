# Proposal: opendesign-quiet-start-icons

## 业主原话(09-23,0.98.10 装上后)

- 「我刚刚打开头上竟然显示正在启动后台还有一段话..这就没必要显示出来了吧,zcode是怎么做的」
- 我问挂多久:「挂几秒差不多,这种东西肯定不能显示出来啊哈哈哈哈」
- 「列表的比如新对话技能这些的图标是不是可以不要了 zcode好像也没有」→ 我核了 ZCode 源码:它**有**图标,是 lucide 细线图标;
  我们的是 ✳⌕◎✦◷⚙ 文字符号(Windows 上各字体粗细大小不齐)。给 A 换 ZCode 同款 / B 全去掉 ⇒ 业主「可以的换成zcode的吧」。

## 做什么

1. 顶上「正在启动后台(有时要一两分钟)…」横幅整条去掉,一个字都不留(ZCode 启动时也没有文字)。后台状态通道(preload/main)保留,不在界面露出。
2. 侧栏「新对话 / 搜索 / 待办事项 / 技能 / 设置」五行的文字符号换成 lucide 细线 SVG(与 ZCode 同源:MessageCirclePlus / Search / ListTodo / Blocks / Settings);
   历史对话行前的 ◷ 去掉(ZCode 任务行前无图标)。

## 不做

- 不加 lucide-react 依赖(五个图标内联 SVG,附 ISC 许可头)。
- 项目行的状态圆点、›/▾/+/✕ 这些小标记不动(业主没点名)。
- 发版另问业主。
