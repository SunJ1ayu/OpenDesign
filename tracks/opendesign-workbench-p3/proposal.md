# Proposal: opendesign-workbench-p3 — 新对话首页(3a)+ 侧栏改版 + keep-mounted

- Date: 2026-07-11
- Status: approved(用户拍板「开工」)

## Goal

照 Claude Design **v2 修订稿**(`handoff/`,20:37 交付)落实:新增 3a「新对话页」
为默认首页,侧栏按 v2 改版,导航模型改为 **3a(默认)⇄ 点项目 → 2a 工作区**;
同时做 keep-mounted(聊天切页隐藏不销毁)——3a 成为主动线后,「切页丢对话」
从边角问题变成主链路断点,不能再挂着。

## Motivation

用户看过 P2 上线的四列工作区(v0.3.0)后带回设计 v2:2a 主工作区本体不动,
增加对话优先的首页与侧栏微调。keep-mounted 此前用户暂缓,新导航模型下必须做
(3a 聊两句→点进项目→回来对话没了 = 主流程断裂)。

## Scope

- in: 3a 新对话页(问候语/620px 大输入卡/三建议 chip/开聊转聊天流)、
  侧栏 v2(删日历行、待办提醒→待办事项、技能上移进全局操作组、去快捷键角标、
  16px 图标列对齐、历史对话 ◷、项目圆点进图标列+当前=赤陶)、
  导航模型(默认 3a;新对话回 3a)、keep-mounted(3a 与 2a 聊天实例常驻,
  切页 CSS 隐藏不卸载)。纯前端,零后端改动。

## Non-goals

- 搜索真功能(v2 只写了定位「精确查找不经 AI」,页面没画;入口保留占位)
- 日历页功能(行删掉,功能将来融进待办页;`#/calendar` 路由与页面一并移除)
- 会话历史回看/恢复(T7)、断线自愈(T6)、tool_hint(T5b)——仍挂起
- 3a 与 2a 聊天互通共享同一条对话(两个独立常驻实例,协议本就每连接一会话)
- AI 内嵌变更卡片、图墙页、深色模式(同 P2 non-goals)
