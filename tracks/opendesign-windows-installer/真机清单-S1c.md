# S1c 真机清单 —— 安装器(业主做,10 分钟)

> **这一趟验的是安装器本身**:装得上吗、要不要管理员、图标对不对、卸载干不干净、
> **卸载之后你的资料还在不在**。
>
> **这一版打开之后会停在"缺 key"那一步** —— 那是预期的,不是坏了。
> 你要的"选大模型 + 填 key"的引导页是下一单(S1d)。

机器这边能判的已经判完了(装的树 21969 个文件逐个对过字节数、配置逻辑 15 条判据
+ 14 条红检、安装器脚本 23 条静态闸 + 22 条红检)。**剩下的都是只有 Windows 能回答的**。

---

## 装之前

这一版**没有代码签名**(买证书要花钱,你之前知道这件事)。所以:

> Windows 大概率会弹一个蓝色的框:「**Windows 已保护你的电脑**」。
> 点 **「更多信息」→「仍要运行」**。这是正常的,不是病毒警告。

如果你机器上已经装着老版本的 OpenDesign(`F:\AI\OpenDesign` 那套),**它不受影响** ——
新的这套装在别的地方(`C:\用户\你\AppData\Local\Programs\OpenDesign`),两边互不干扰。

## 这一趟**不问**的事(先说清楚,免得日后把这张收据读过头)

- **缺 WebView2 的老机器上会怎样** —— 你两台机器上 WebView2 都在,这条兜底路径大概率
  不会被走到。收据只能证明"检测逻辑没炸",证明不了"补装真的成功"。
- **任务栏图标** —— 窗口起来之后任务栏显示的还是 Python 的图标(改它要在 Windows 上
  设窗口图标,那层我在 Linux 上一条考卷都跑不了)。第 5、6 条问的是快捷方式的图标,
  那个是对的。**如果这件事你在意,告诉我,我单独做一单。**
- **开机自启真的生效没有** —— 要重启电脑才知道,这一趟不问。
- **覆盖安装 / 装第二次** —— 没验。
