## 这一趟**不问**的事(先说清楚,免得日后把这张收据读过头)

- **`key.txt` 的文件权限**:Windows 上是 ACL 语义,和 Linux 完全不同。
  **本单不声称"别人读不到这个文件"**,只声称我们自己不到处乱写它。
- **缺 WebView2 / .NET 的老机器**:你两台机器上都有,这条兜底路径大概率走不到。
  我只能证明"检测逻辑没炸",证明不了"补装真的成功"。
- **任务栏图标**:窗口起来后任务栏显示的可能还是 Python 的图标(第 5 条问的是快捷方式
  图标,那个是对的)。**在意的话告诉我,单独做一单。**
- **开机自启真的生效没有**:要重启电脑才知道,这趟不问。
- **从旧位置自动搬数据**:你机器上没装过 0.86/0.87,所以"从旧安装目录搬过来"这条
  真机上验不到。第 18 条验的是"卸载不丢",A 验的是"重装接得上"。
- **装到别的盘(D:)**:代码里做了跨盘兜底,但没有真机证据。愿意的话把第 1 步的路径
  改到 D 盘再走一遍 15~18,那条就有证据了。
