# 真机清单 —— 0.89.0(业主在 Windows 上走一趟)

装 `OpenDesign-Setup-0.89.0.exe`。**每条都是"我在 Linux 上验不了"的**;
能自动验的已经全在判据里了,这里只剩必须用眼睛和手的。

一条一条来,红了就停下来告诉我,别接着往下走。

---

## A. 先确认装的是新的(不确认这一条,后面全白做)

- [ ] **A1** 打开 OpenDesign,窗口能出来。
- [ ] **A2** 在浏览器里开 `http://127.0.0.1:8766/api/health`,里面的 `version` 是
      **0.89.0**。
      > 盘上和运行时对不上 = 停,别往下走。08-16 之前栽过两次同一种病。

## B. 这一版要修的那件事(0.88.0 就死在这儿)

- [ ] **B1** 在界面里填大模型 key,保存。
- [ ] **B2** 等十几秒,**聊天连得上**(能发出去一句话、能收到回话)。
- [ ] **B3** 关掉 OpenDesign,**再打开一次** —— 不再有
      `NameError: name 'env' is not defined`,正常进界面。
      > 这一条是本单的命根子:0.88.0 从这里开始每次打开都崩。
- [ ] **B4** 再关一次、再开一次(第三次)。仍然正常。

## C. 重启网关不再留垃圾 / 不再假报警

- [ ] **C1** 开着任务管理器(详细信息,按名字排序看 `python.exe` / `pythonw.exe`),
      记下现在有几个。
- [ ] **C2** 到设置里把 key **再保存一次**(会触发一次网关重启)。等它连上。
- [ ] **C3** 回任务管理器:python 进程数**回到 C1 那个数附近**,
      没有多出一堆(以前每保存一次会多留 3 个孤儿工具服务)。
- [ ] **C4** 保存 key 的那十几秒里,**没有**弹出「网关 意外退出了,请退出后重新打开」。
      > 弹了就是 c19 那个误报没修干净,告诉我。

## D. 新窗口(这一版改动最大、也最没证据的一块)

- [ ] **D1** 窗口**顶上没有系统标题栏**了 —— 看不到第二个 "OpenDesign" 标题,
      也没有地址栏。
- [ ] **D2** 左边侧栏的标题是 `OpenDesign`,**后面那个点没了**。
- [ ] **D3** 右上角有三个按钮:最小化 / 最大化 / 关闭。
- [ ] **D4** 点最小化 → 缩到任务栏;从任务栏点回来 → 窗口回来。
- [ ] **D5** 点最大化 → 铺满屏幕,**但不盖住任务栏**(底下那条还看得见)。
      再点一次 → 回到原来的大小和位置。
- [ ] **D6** 双击顶上那条空白 → 也能最大化/还原。
- [ ] **D7** 按住顶上那条空白**拖动窗口**,能拖走。
- [ ] **D8** **八个方向都试一下拖着改大小**:上、下、左、右、左上、右上、左下、右下。
      鼠标移到边上时指针会变成双箭头。
      > 这八个是我自己接回来的 —— 无边框之后 Windows 不再提供边框拖拽。
      > 哪个方向没反应,告诉我是哪个。
- [ ] **D9** 点右上角的 × → 窗口**收进托盘**(程序没退出,托盘图标还在)。
      双击托盘图标 → 窗口回来。
- [ ] **D10** 托盘图标右键 →「退出」→ 程序真的退干净。
- [ ] **D11** 在界面里正常**选中一段文字**、拖动滚动条 —— 不会变成"拖着整个窗口跑"。

## E. 已知偏差(看一眼就行,**不是 bug,别报**)

- [ ] **E1** 如果你把窗口拖到屏幕**最上边**让 Windows 自己贴边最大化,
      这一种最大化**会盖住任务栏**。点我们右上角那个最大化按钮则不会。
      > 原因:那一路是 Windows 自己接管的,不经过我的代码。修它要动更底层的
      > 窗口过程,代价大于收益,所以这一版接受它。你觉得碍事再说,我再想办法。

(要 Windows 桌面会话才跑得起来)。真坏了的话:
