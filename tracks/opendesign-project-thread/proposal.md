# Proposal: opendesign-project-thread(Track E:项目级对话上下文)

- Date: 2026-07-16
- Status: open

## 背景(用户 07-16 反馈 #2)
工作区右列「项目助手」单实例全项目共用一条会话:A 项目说完切 B,上下文串了。
用户要求每项目独立上下文,并梳理"单项目上下文管理 × 历史对话窗口"的关系。

## 方案(07-16 已与用户对齐)
每项目一条「工作对话」:前端 localStorage 存 项目→chat_id 映射;切项目=切会话
(有映射 attach 回放续聊,无映射强制新会话);新开项目会话首条消息自动带
「【当前项目:X】」前缀 + AGENTS.md 规则(默认项目=X);历史列表全局不变、命中
映射的会话加项目名小标;项目列「+ 新对话」=断开映射重开。首页 3a 实例不动。
复用 p6 attach/thread 回放机制,零后端/零协议改动。ds-web 0.19.0 → 0.20.0。

## 非目标
- 每项目多条对话的管理(项目内历史列表)——等真实使用需求。
- 跨设备映射同步(localStorage 本机;丢=重开新对话,PKB 数据零损失)。
