# Proposal: opendesign-todo-v3

- Date: 2026-07-16
- Status: open

## 背景(真机反馈 07-16,两条实证)
1. 待办页右边空太多(`.todo-cards max-width:860px`),长事项被省略号截断
   (`.todo-row .txt` nowrap+ellipsis)——用户要求全文完整显示。
2. 待办需要按"批次"分层:如「2026-07-16 的修改意见」一个层级,点开展开。
   与"业主反馈一次贴入=一批同日期变更"(后续 Track D)天然咬合。

## 方案
- 布局:卡片宽度 860→1100px;正文允许换行完整显示,行内元素顶对齐。
- 分组:项目卡内改为**按日期分批**(倒序,最新一批默认展开,其余收起,点头部
  切换);空间从"小节"降级为行内标签。按时间视图同样按日期加组头。
- `groupBySpace` 随之成为死代码,删净(含其 oracle 用例)。
- 零 schema / 零后端改动;ds-web 0.17.0 → 0.18.0。

## 非目标
- 变更行不加"类别"字段(修改意见 vs 进度)——日期批次先覆盖,真实使用再议。
- 业主原文展示(Track D 二期)。
