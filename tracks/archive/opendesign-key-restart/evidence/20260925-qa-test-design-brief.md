你是这个团队的**测试工程师**。现在是测试设计阶段:**修复还没开发**。请站在**真实用户**的角度写测试设计。
**不要读代码实现**(黑盒测试;需要的信息都在下面)。不要写「以后有人改坏代码会怎样」「手工改配置文件 / 手删文件才会碰到」这类用例 ——
产品负责人明确说过这类是「有人拿锤子砸墙墙会不会裂」,不测。不要联网。

## 产品是什么
OpenDesign:室内设计师(产品负责人本人,不是程序员)用的 Windows 桌面 AI 助手(Electron 窗口)。
聊天要用大模型,模型来自几家厂商,每家填自己的 API Key、扣各自的钱:MiMo(小米)、DeepSeek、Kimi、GLM 套餐、GLM 按量,
还能「添加供应商」接自定义的 OpenAI 兼容地址。软件会自动更新。
界面:左侧栏(工作区、聊天、设置);聊天页输入框右下角有「换模型」按钮(点开按厂商列出模型,只列已经填了 key 的厂商);
「设置 → 模型设置」页:左栏厂商列表,右栏这家的 Base URL、API Key(保存)、模型列表(每行:测试 / 编辑 / 删除)、添加模型。

## 产品负责人原话(09-25,当前版本 0.98.12)
- 「我切换模型填入api key之后 新对话一直显示链接不上gateway」
- 「重启之后可以了」
- 「但是我换模型列表没有可以点击的地方，只有一个测试一个编辑。。你让我怎么换模型呢，聊天列表只要我填一次apikey之后就一直显示连接不上gateway 然后输入框右下角没有模型选择框了」
- 「zcode是怎么做到切换模型直接能用的」
- 「那就直接改成zcode那样不就好了吗」

## 现在的样子(要被修掉的)
- 在设置页给任意一家存 key ⇒ 软件在后台把「聊天服务」重启一次,想让新 key 生效。
- 在 Windows 上这次重启会卡死:聊天页一直显示「连接不上,gateway 可能没在跑」,输入框右下角的换模型按钮也跟着消失(它只在连上时显示)。
  只有从托盘退出、再打开才好。
- 全新安装、还没填过任何 key 时:聊天服务先不启动,在设置页填第一把 key 时由上面同一个「重启」把它起起来(同样会卡)。

## 要做成的样子(照 ZCode:存了就能用)
- 聊天服务**在跑**时存 key(新填一家 / 改一家的 key / 添加带 key 的自定义供应商):**不再重启**,聊天不断、换模型按钮一直在;
  下一句对话起就用新 key。设置页提示改成类似「已保存,下一句对话起就用它」。
- 聊天服务**没在跑**时(全新安装、第一次填 key):存 key 后自动把它启动,提示「正在启动后台服务,稍等片刻」;几秒后聊天页自己连上。
- 设置页模型列表**仍然不能直接点着换模型**(ZCode 也是这样);换模型在聊天框右下角那个按钮里。
- 修掉 Windows 上「后台服务启动时卡死」那一处(以后第一次填 key 起服务也要靠它)。

## 已定的规矩(不变)
- 存 key **不会**换掉你当前正在用的模型;要换模型在聊天框里选。
- key 在界面上永远只显示首尾几位,不显示原文。
- 老装法(不是 Windows 安装包、开发者用源码跑的)没有自动生效这件事,仍提示「请手动重启」。

## 这次请特别多想三类(上一单测试设计漏掉的都在这里)
1. **失败路径**:key 填错、那家服务连不上、存到一半出错、聊天服务起不来 —— 用户看到什么、能不能自己走出来。
2. **组合场景**:两件事叠在一起(例如:正在等回复时存 key;刚装好只填了自定义供应商;改了当前那家的 key 又马上换模型;存完立刻发消息)。
3. **跨功能影响**:这次改动会碰到的别处(自动更新后 key 还在、原来用着的模型照常、定时任务 / 其他页面)。
