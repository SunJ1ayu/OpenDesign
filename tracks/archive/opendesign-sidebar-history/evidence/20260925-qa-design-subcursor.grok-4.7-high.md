我先核对仓库快照和评审 diff，确认侧栏现状与方案描述是否和文件一致，再据此写测试设计。
仓库里只有 `README.md` 写明这是黑盒测试台、故意没有代码；`review.diff` 是空的。下面的期望结果全部按题面写，没有对照实现，也没有跑过软件。

Direction: 把侧栏测成「同一批对话的两种索引」：按时间用来找回，按项目用来对上工地；置顶只是多一个入口，对话仍留在原来的日期段和项目下面。验收只写室内设计师点得着、看得懂的结果。
Core bet: 开发前没有界面可对，真正会让人做错事的是对话挂错项目，或记录看起来丢了。口径锁定为：助手对项目动过手（记账、改阶段、读档案、记沟通等）或这条就是该项目的项目对话，才算有关；只是说出项目名仍留在「其他对话」。一段对话碰过几个项目，就在这几个项目下各出现一次。删项目只去掉项目行，聊天还在。
How it works: 用户故事按「找回、归类、置顶改名、删除、项目没了、助手没连上、边聊边变、旧入口还在」写 Given / When / Then。用例步骤全是侧栏上的点击。P0 只给「找不到对话」和「会误以为记过账或记录没了」。探索任务留给做好后的真界面，专门看题面没写死的节奏。
Best at: 在还没开发时，把「和这个项目有关」、置顶与原列表是否同一条、项目删除后对话去哪，写成屏幕上能判定的通过标准。
Sacrifices: 不测改配置、手删本地文件、代码被改坏。不测「先显示几条」的具体数字（题面没给）。阶段折叠、项目展开是否重启后还保持，不作为通过条件；要通过的持久化只有视图切换、置顶、改名。
Blind spots in the brief: 置顶后原位置还留不留、删项目后「项目对话」本身还在不在、侧栏点「项目对话」是回首页还是进项目页、今天/昨天按哪一个时间、多个项目的小标怎么画、新建项目展开后有没有一条空的项目对话，题面都没写死。
Smallest first step: 先请产品负责人确认第 4 节五条口径；开发第一版只做能点的侧栏，用 TC-01、TC-03、TC-05、TC-06、TC-07 验收「翻到最早一条接着聊」和「动手才挂到项目」。

已锁定、下文用例都按这个写：

- 今天 / 昨天 / 更早按最后一条消息的电脑本地日期；同一天里新的在上。过了零点又说了一句，整段只出现在「今天」。
- 某个项目下：项目对话永远第一条，其余按最近活动从新到旧。
- 「已置顶」在两个视图的对话列表最上方，有置顶才出现。这里多一行入口；按时间的日期段、按项目的项目下仍留着同一条。已置顶里同一段只一行。
- 改过的名字优先。软件后来自动概括时，不盖住用户改的名字。
- 空名字、只打空格，都不能保存，这一行仍显示旧名。
- 完全退出再打开后，视图、置顶、改名还在。
- 助手没连上时，侧栏仍用这台电脑上已有的对话和项目；没记下的动作不算「动过手」。

## 1. 用户故事 + 验收标准

**故事 1：把更早的对话找回来接着聊**

- Given 我有今天、昨天、更早的对话，最早那条不在第一屏。
- When 我第一次打开侧栏（从没拨过「按时间 | 按项目」）。
- Then 「按时间」是选中的。历史按「今天」「昨天」「更早」分段，没有对话的那一段不占一截空标题。我点翻页，最早那条会出现。我点它，回到首页，看到当时的内容，可以继续说。翻页控件每点一次都多出更早的对话；最早一条已经在列表里之后，不会再翻出重复的一段。

**故事 2：记住我上次怎么看**

- Given 我上次拨到「按项目」后完全退出。
- When 我再打开软件。
- Then 侧栏仍是「按项目」。我从没拨过时，打开就是「按时间」。来回拨几次，对话没有变成两份，置顶和改过的名字保持不变。

**故事 3：按工地把对话收在一起**

- Given 「城南别墅」在「施工跟进」。它有一条项目对话。我另外在首页让助手给它记过账，这笔比项目对话里最后一句更新。
- When 我拨到「按项目」，展开「城南别墅」。
- Then 项目仍按阶段分堆，堆可以折叠。展开后项目对话在第一条，记过账的那段在它后面。我点项目名，进入城南别墅的项目页。我点其中任意一条（含项目对话这一行），回到首页接着聊，内容和项目页右边那一栏是同一段，不是一段新的空白聊天。

**故事 4：怎样才算跟这个项目有关**

- Given 甲：助手给城南别墅记过变更，又给滨江样板间改过阶段。乙：我只说了「城南别墅下周开工」，助手没有记账、改阶段、读档案、记沟通。丙：闲聊，没碰任何项目。
- When 我看「按项目」。
- Then 甲在城南别墅、滨江样板间下面各有一行，不在最底下的「其他对话」。乙和丙只在「其他对话」。按时间里，甲的名字后面能看出它跟这两个项目都有关。

**故事 5：置顶和改名关掉再开还在**

- Given 一段对话出现在「今天」，也出现在城南别墅下面。
- When 我点这条右边的「⋯」，置顶，并把名字改成「给甲方的预算口径」，然后完全退出再打开。
- Then 最上面出现「已置顶」，里面是这个新名字，且只有一行。日期段和城南别墅下面仍有同一条，名字也是新的。我取消置顶后，这一条从「已置顶」消失；若没有别的置顶，整个「已置顶」区不出现。日期段和项目下面那一行还在。

**故事 6：删掉置顶过、改过名的对话**

- Given 一条已置顶、已改名的对话，在已置顶、日期段、相关项目下都能看见。
- When 我点「⋯」→ 删除。
- Then 先看到确认，确认里写的是我改过的名字。我点取消，所有位置都还在，名字和置顶不变。我再确认删除，它从已置顶、日期段、各个项目、「其他对话」一起消失。完全退出再打开，仍然没有它。

**故事 7：名字空了或特别长**

- Given 一条对话当前名叫「客厅地面」。
- When 我把名字改成空的，或只打几个空格，然后确认。
- Then 这一行仍显示「客厅地面」，我能看出这次没改成功。
- When 我改成一句很长的名字并确认，再完全退出打开。
- Then 侧栏这一行被截断，「⋯」仍点得着。再打开改名时，全文还在。

**故事 8：项目改名、换阶段、被删掉之后，聊天还在**

- Given 城南别墅下面有项目对话，还有一段我改过名、置过顶的首页对话；这段首页对话没有碰过别的项目。
- When 我把项目改名为「城南别墅二期」。
- Then 阶段堆里的项目行、展开后的对话、按时间名字后面的项目标记，都变成「城南别墅二期」。我改过的对话名不变。
- When 助手把这个项目的阶段从「洽谈」改成「施工跟进」。
- Then 项目行连同它下面的对话出现在「施工跟进」，「洽谈」里不再有这个项目。
- When 我在软件里删除这个项目并确认。
- Then 项目行没了。那段首页对话按时间仍能找到，名字和置顶还在；按项目时它出现在「其他对话」。项目对话也还在「其他对话」里，点开仍是原来的内容。

**故事 9：助手没连上时，我仍能翻旧对话**

- Given 电脑上已经有历史对话和项目，此时助手连不上。
- When 我翻「显示更多」、拨到「按项目」、打开一段旧对话，并试着再发一句、试着让它记账。
- Then 侧栏不是空白，今天/昨天/更早、项目堆、已置顶都还在。旧对话点得开，能看见以前的内容。发送失败能看出来。这段对话不会因此出现在某个项目下面。

**故事 10：正聊着的时候，侧栏马上跟着变**

- Given 侧栏停在「按项目」，城南别墅是展开的。我新开一段对话，第一句就让助手把一笔记进城南别墅，并且助手明确记下了。
- When 记账完成，我不用重开软件。
- Then 这段新对话出现在城南别墅下面、项目对话之后，同时出现在「今天」。「其他对话」里不再有它。
- Given 记账没有成功。
- Then 它留在「其他对话」和「今天」，不出现在城南别墅下面。
- Given 我正在项目页右边的项目对话里继续说，侧栏按项目且该项目展开着。我没有手动改过这条的名字。
- When 我又发了几句。
- Then 项目对话仍是该项目下第一条。侧栏上的自动概括会更新。若我已经改过名，侧栏继续显示我改的名字。

**故事 11：原来的侧栏还能用**

- Given 侧栏已经有「按时间 | 按项目」和「已置顶」。
- When 我新建对话、搜索、折叠阶段堆、新建项目、从历史点回一段对话、打开待办页助手再回到侧栏。
- Then 新对话出现在「今天」，没碰项目之前也在「其他对话」。搜索能打开更早的对话，能按我改过的名字找到，已删除的找不到。折叠阶段堆后，里面的项目和对话收起；再展开，项目还在。新建项目出现在对应阶段，展开后有一条可点的项目对话。待办页里让助手给某项目记过沟通的那段，会出现在该项目下面。

| TC-26 | P1 | 侧栏按项目，城南别墅展开着 | 新对话里要求记账，但助手明确没有记下 | 这段在「今天」和「其他对话」。城南别墅下面没有它 | 失败路径 |

## 3. 探索式测试任务

1. **把时间线翻穿**  
   目标：确认「显示更多」能走到最早，且和「按项目」是同一批对话。  
   重点：今天/昨天/更早有没有空标题；同一段会不会在一个日期段里出现两次；拨过去再拨回来有没有少一行。

2. **一段话里忙两个工地，顺口提第三个**  
   目标：核对「动过手才挂项目」。  
   重点：两个项目下各一行、项目对话仍在各自第一条；只被提到的第三个项目下面没有它；「其他对话」不再收留已经挂上项目的那段；改阶段后项目是否连对话一起换堆。

3. **项目页边聊，侧栏边钉边改名，再退出删除**  
   目标：看实时更新和持久化是不是同一条对话。  
   重点：右栏新句子时侧栏第一条是否还是项目对话；改名会不会被自动概括盖住；已置顶会不会变成两行；确认框是不是新名字；确认后各处是否一起消失。

4. **助手连不上时找回昨天的方案**  
   目标：断线时侧栏仍能当目录用。  
   重点：侧栏会不会空白或一直转；旧对话打不打得开；失败的发送会不会让这段误挂到项目下；置顶和改名此时还改不改得了。

5. **用改版前的习惯走一遍**  
   目标：新切换没有吃掉原来的入口。  
   重点：新对话、搜索改后的名字、折叠阶段、新建项目、点项目进项目页、首页/项目右栏/待办页三处聊完后侧栏是否都收得进去。

## 4. 需要产品负责人拍板的疑问

1. **置顶后原位置还留不留。** 用例按「已置顶多一行入口，日期段和项目下仍留着同一条」写了 TC-08、TC-16。若置顶等于从原处搬走，这两条要改成：置顶后日期段和项目下不再有这一行。
2. **删除项目后，项目对话还在不在。** 普通首页对话和项目对话，用例都按「项目行消失，聊天还在；只跟这个项目有关的改到其他对话」写了 TC-13。若项目对话应随项目一起消失，TC-13 里只改项目对话那一条：按时间和其他对话都看不到它。
3. **侧栏点「项目对话」这一行去哪。** 用例按题面写了 TC-03：回首页接着聊，且和项目页右栏是同一段。若这一行应打开项目页右栏，TC-03 要改成进入项目页，并看到同一段内容。
4. **今天/昨天按哪个时间，新的在上还是在下。** 用例按「最后一条消息的电脑本地日期，新的在上；过零点又说一句就只留在今天」写了 TC-01、TC-03、TC-19。若按创建日期、过零点不搬，这三条的分段和排序要改。
5. **项目小标，以及没聊过的新项目。** 用例按「按时间能看出关联的每一个项目；新建项目一展开就有一条可点的项目对话」写了 TC-06、TC-21。若多个项目只显示一个名字，或第一次开口前不出现对话行，这两条的期望要改。
