# 测试设计(QA,开发前):OpenDesign 侧栏「历史对话 + 项目」改版

你是这个团队的**测试工程师**。现在是测试设计阶段:**还没开发**。请站在**真实用户**的角度写测试设计。
你拿到的目录里故意没有代码(黑盒测试;需要的信息都在下面)。不要写「以后有人改坏代码会怎样」「手工改配置文件 / 手删文件才会碰到」这类用例 ——
产品负责人明确说过这类是「有人拿锤子砸墙墙会不会裂」,不测。不要联网。

## 产品是什么
OpenDesign:室内设计师(产品负责人本人,不是程序员)用的 Windows 桌面 AI 助手。聊天有三处:首页聊天、每个项目的「项目助手」栏、待办页的助手栏。
每个项目有一条自己的「项目对话」(在项目页右边那栏聊的就是它)。助手能干活:记一下(记进项目变更账本)、改项目阶段、记沟通、读项目档案……
左侧栏:新对话 / 搜索 / 待办事项 / 技能,下面「历史对话」,再下面「项目」(按阶段分堆:洽谈 / 平面方案 / 施工跟进…,每堆能折叠;点项目进项目页)。

## 侧栏现在的样子(要被改的)
- 「历史对话」只显示最近 2 条,旁边「全部」点了没反应 ⇒ 更早的对话找不到。每条鼠标移上去能删(要确认)。
- 碰过某个项目「项目对话」的那条,名字后面带一个项目小标。
- 对话的名字是软件自动起的一句概括;不能改名、不能置顶。

## 要做成的样子(方案一 + 方案二一起,产品负责人同意的;细节是我们定的)
- 侧栏多一个切换「按时间 | 按项目」,记住上次选的(默认按时间)。最上面「已置顶」(有置顶才出现)。
- **按时间**:「历史对话」按 今天 / 昨天 / 更早 分段,先显示一部分,「显示更多」能一直翻到最早的;下面「项目」栏和现在一样。
- **按项目**:「项目」栏和现在一样按阶段分堆,但每个项目行能展开,下面列出和这个项目有关的对话(项目对话在最前,其余按时间);
  最下面一堆「其他对话」放没碰过任何项目的对话。点项目名照旧进项目页;点一条对话回首页接着聊。
- 「和这个项目有关」= 在这段对话里,助手对这个项目动过手(记过变更、改过阶段、读过档案、记过沟通……),或者它就是这个项目的项目对话。
  **一段对话碰过几个项目,就在几个项目下都出现。** 只在嘴上提了项目名、助手没对它动手的,算「其他对话」。
- 每条对话右边「⋯」:置顶 / 取消置顶、改名、删除(删除照旧要确认)。置顶和改的名字**关掉软件再打开还在**。

## 这次请特别多想三类
1. **失败路径**:删掉一个置顶的 / 改过名的对话;项目被改名 / 删除后,它下面原来的对话去哪;改名改成空的 / 很长的;聊天服务没连上时侧栏什么样。
2. **组合场景**:同一段对话碰了两个项目;在项目页正聊着(对话在变),侧栏同时开着「按项目」;新对话第一句就让助手记账(它该马上出现在那个项目下吗);
   置顶的对话同时出现在置顶区和原来的位置吗;在两个视图之间来回切。
3. **跨功能影响**:原来的项目栏(分堆、折叠、点进项目页、新建项目)、历史行删除、新对话、从侧栏点回一段对话接着聊、项目页右栏的项目对话、搜索。

1. **用户故事 + 验收标准**:每个故事写 Given / When / Then(用户看得见的结果)。
