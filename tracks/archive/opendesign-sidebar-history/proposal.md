# Proposal: opendesign-sidebar-history

- Date: 2026-09-25
- Status: open(0.98.14 三件里的第 3 件;① opendesign-chat-error-visible、② opendesign-composer-zcode 已归档;之后一张发版单)

## Goal

侧栏的历史对话与项目照对照图「方案一 + 方案二」一起改(https://claude.ai/artifact/5i6XuidFAHmreW6ATA2jjF,「历史对话和项目」页):
方案一 = 历史对话看得全(今天 / 昨天 / 更早分段 + 显示更多)、能置顶、每条「⋯」置顶 / 改名 / 删除;
方案二 = 可以切成「按项目」看:每个项目下挂和它有关的对话,没碰过项目的放「其他对话」。

## Motivation

现在侧栏历史只显示最近 2 条,「全部」按钮是空的 ⇒ 更早的对话找不到(`web/src/workspace/Sidebar.tsx` `recent = sessions.slice(0, 2)`;App 只拉 10 条);
对话只能删,不能置顶、改名。上一单的 QA 也看到:业主先聊了项目,首页那段就从侧栏挤掉、点不回去(上上单 Q5′ 落点就是这一单)。

## 真问题(第一性)

- 用户原话:09-24 看 ZCode 时提「历史对话和项目怎么参考一下 zcode」;09-25 12:5x「还有昨天说的历史对话和项目怎么参考一下zcode」;
  13:3x 看完对照图「直接方案一和方案二一起做吧」。两个方案的具体内容是**我提的**(对照图便签),业主没有逐条改。
- 真正要解决的是:① 过去的对话找得回来(不只最近 2 条);② 常用的对话固定在上面、名字认得出;③ 在某个项目上干活时,和它有关的对话一眼看全。
- 我在这中间翻译了什么:
  - 「方案一 + 二一起」→ 一个切换「按时间 | 按项目」:按时间 = 方案一(下面项目栏照旧);按项目 = 方案二(项目栏每个项目能展开它的对话 + 最下「其他对话」)。
  - 「每段对话碰过哪个项目」→ 从已有的对话记录读出来:助手的项目工具调用参数里带项目名(已查:`<workspace>/sessions/*.jsonl`),
    加上项目对话首句的「【当前项目:X】」,加上前端已有的项目对话映射。规则(我提、业主没反对):**碰过哪个项目,就在哪个项目下都出现**。
  - 置顶 / 改名存哪:网关自带的侧栏状态文件(`~/.nanobot/webui/sidebar-state.json` 里 pinned_keys / title_overrides),或本机浏览器存储 —— 待 4c 定。
- 用户可观察的成功:在真软件里 ① 侧栏能翻到很早的对话;② 置顶的一直在最上、关掉重开还在;改的名字关掉重开还在;删了就没了;
  ③ 切到「按项目」,点开一个项目看到它的项目对话和聊过它的其它对话,点一条回到那段对话;没碰过项目的在「其他对话」;
  ④ 原有的:点项目进工作区、按阶段分堆与折叠、新对话、历史行删除确认,一样都不能坏。

## Scope

- in:`web/src/workspace/Sidebar.tsx`(两种视图、分段、显示更多、⋯ 菜单、置顶区)、`web/src/App.tsx`(拉更多对话、项目关联、置顶改名)、
  新纯函数模块(分段 / 分组 / 合并关联)、`bin/ds_web.py`(读对话碰过哪些项目的 GET 接口;置顶 / 改名若存网关则加窄写口)、样式;判据;QA 设计 / 执行。

## Non-goals

- 不改 nanobot(钉版本、零改动底座);不做 ZCode 的「分组」「归档」「标记未读」「排序方式」「时间线」以外视图;不做对话搜索(已有全局搜索);
  不改项目栏「按阶段分堆」与点项目进工作区;不改标题生成(上一单 Q2 实为录像台子假厂商把标题也回成同一句,见 design)。

## 验收边界与轮次预算(要外审的单开工就写 —— panel 抽屉 4b)

- 这一单承诺:
  1. 按时间:历史对话按 今天 / 昨天 / 更早 分段,首屏若干条 + 显示更多能翻到最早的;项目小标照旧。
  2. 每条「⋯」:置顶 / 取消置顶、改名、删除(删除照旧要确认);置顶区在最上;置顶与改名关掉软件重开仍在。
  3. 按项目:项目栏照旧,每个项目能展开它的对话(项目对话在前),一段对话碰过几个项目就在几个项目下出现;最下「其他对话」;点对话回首页续聊。
  4. 两种视图切换记住上次选的。原有的项目栏、历史删除、新对话、续聊不坏。
- 不承诺:对话碰过项目的判断只看助手用项目工具的记录与项目对话 —— 业主只在嘴上提了项目名、助手没动项目工具的对话,归「其他对话」;
  「测试挡不住任意未来的错误实现」。
- 实质评审上限:**2 轮**。impact 见 decision(若加网关写口 = high,每轮 2 家)。第 2 轮主要核验修复;用完有阻断就保持未完成,不自动续轮。
  **每轮派发前先跑 `track preflight opendesign-sidebar-history`。**
