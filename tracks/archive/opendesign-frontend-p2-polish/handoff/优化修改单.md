# 优化修改单(对照 v0.30.0 实现截图)

> 目标:成熟的前端质感。配合设计稿最上方「6a 组件规范」画板(`screenshots/10-组件规范.png`)执行。
> 三条全局原则:**输入范式唯一、按钮三级、一切可点必有 hover + cursor:pointer(120ms ease 过渡)**。
> 输入卡的发送按钮统一为文字按钮「发送」(主色 #c46a4a 底白字、圆角 8px、600 字重),不用 ↑ 图标;未连接置灰态同形但底色 #e8d5cb。

## A. 全局(所有页面)

1. **输入范式唯一**:全应用禁止裸方角 `<input>`。所有输入 = 白底 `#fff`、边框 `1px solid #ddd8ca`、圆角 10–14px、聚焦边框转 `#c46a4a`(不要浏览器默认 outline)。涉及:变更快记行、访问口令、文件搜索、⌘K 输入行。
2. **按钮三级**(圆角统一 8px):
   - 主按钮:`#c46a4a` 底白字,hover `#a04f2e`,字重 600。每屏至多一个:「连接」「记一条」「关联」。
   - 次按钮:白底、边框 `#ddd8ca`、字 `#5c574c`,hover 底 `#f3f1ea`:「扫描整理」「打开文件夹」「添加技能」。
   - 文字链接:一律 `#a04f2e`:「去项目 →」「全部」「图墙 →」。
   - 现状问题:「记一条」长得像灰字链接、「连接」是大方块——都按上面收口。
3. 焦点可见:键盘 Tab 焦点用 2px `#c46a4a` 外圈;esc 关一切弹层。

## B. 变更快记行(项目工作区,重点)

现状:裸方角 input +「空间(可选)」独立下拉 + 灰字「记一条」,与聊天输入卡完全两个范式。
改为**单行输入卡**(见 6a-B):
- 圆角 12px 卡内:左 `✎`(`#c46a4a`)→ 占位「记一条变更,如:玄关柜改到 2.4 米,柜顶留检修口…」→ 右内嵌「空间 ⌄」chip(28px 高描边胶囊,选中后显示空间名)→ 主色「记一条」按钮(28px 高)。
- 回车 = 提交;空间不选则 AI 从内容猜,猜不出记「未分类」。
- 提交后:输入卡下方闪现轻提示「已记入 C13」(绿色,2s 淡出),新行插入列表顶部并短暂高亮底色 `#f7ecd8`。

## C. 「连接聊天服务」(第二重点)

现状:裸表单直接放在新对话页 C 位 / 项目工作区聊天列中央,像报错页。
- **新对话页**:改为居中一张 360px 连接卡(见 6a-③):白底圆角 16px 投影、标题 + 一句说明(**必须说明"变更记录、图墙、文件不受影响,现在就能用"**)+ 口令输入(统一范式)+ 主按钮「连接」+ 小字「口令在 nanobot WebUI 设置页获取」。
- **项目工作区聊天列**:不放表单。顶部一条琥珀横幅「未连接聊天服务 · 连接」(点击弹出同一张连接卡为 modal),下方保持空,底部置灰输入卡「连接后可用…」照旧。
- 连接成功后所有入口消失,口令存本机;连接失败在卡内行内报错(红字 12px),不弹 alert。

## D. 项目工作区伴随列(信息过载)

1. **收件箱卡**:默认收成一行摘要 `收件箱 2 · [扫描整理]`(次按钮),点行展开明细;不要默认占三行文件列表 + 说明文字。
2. **「方案深化 · 张伟 · 7-01」速览行**:信息价值低,删掉;阶段如需保留,并入中央列项目标题右侧一个小 chip。
3. 「图片」「项目文件」组标题、计数、链接样式统一:标题 13.5px/600,计数 11.5px `#98917f`,右侧链接 `#a04f2e`。
4. 文件夹行(01-资料 / 02-参考图 / 06-效果图)与「最近更新」组头统一为 10.5px `#b0a996` letter-spacing .06em。

## E. 变更行操作(引导点击)

1. hover 浮现的「编辑」灰字改为**图标按钮组**:`✎`(编辑)+ `✓`(标记完成),28px 方形描边按钮,hover 底 `#f3f1ea`(✓ hover 字转绿 `#3d7a4e`)。
2. 状态胶囊带 `⌄` 可点改状态——保留,补 `title="点击修改状态"`;弹出的状态菜单用与设置弹层同款卡片样式。
3. 变更行整行 hover 底色 `#f9f7f1`,让"这行可交互"可感知。

## F. 空态引导(每个空态 = 一句话 + 一个可点动作)

- 变更记录空态:文案保留,下面加次按钮「记第一条变更」→ 聚焦快记行。
- 图片空态:加次按钮「打开文件夹」;文案里「登记参考图」加 `#a04f2e` 色可点(预填聊天)。
- 未关联文件夹项目:下拉 + 「关联」主按钮——保留,但下拉也要统一输入范式(圆角 10px 描边)。
- 侧栏「连接聊天后显示」占位:未连接时整组隐藏,连接后无对话显示「暂无对话」。

## G. 待办事项页

1. 「按项目」视图:项目卡内**按空间分小节**(玄关/客厅…,小节眉 = 空间名 + 浅分隔线 `#f0ede4`),不要按日期折叠——日期折叠留给「按时间」视图(现在两个视图都按日期,重复了)。
2. 内容区最大宽 ~880px 居中即可;卡片间距 14px。
3. 「⚑ 18 天没动静」标签样式对了;底部灰字「其余 N 个项目…」保留。

## H. 其他小项

- ⌘K 面板:输入行统一范式;分类 chip 选中态黑底白字(已对);结果行 hover `#f3f1ea`、选中 `#ece9e0`。
- 图墙相册:封面卡 hover 加 `translateY(-2px)` + 投影加深,暗示可点;lightbox 加 esc/点击遮罩关闭 + 左右键切换。
- 侧栏项目行「未建档」标签:字色 `#b0a996`,hover 行出现「建档 →」链接。
- 设置弹层版本号等保留;「深色即将支持」chip 保留。
