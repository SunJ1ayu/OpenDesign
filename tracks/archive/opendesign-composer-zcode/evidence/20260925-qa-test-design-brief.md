# 测试设计(QA,开发前):OpenDesign 聊天输入框改版(「+」菜单 / 打 / 选技能 / 模型按钮带厂商名 / 停止键 / 问候语)

你是这个团队的**测试工程师**。现在是测试设计阶段:**还没开发**。请站在**真实用户**的角度写测试设计。
你拿到的目录里故意没有代码(黑盒测试;需要的信息都在下面)。不要写「以后有人改坏代码会怎样」「手工改配置文件 / 手删文件才会碰到」这类用例 ——
产品负责人明确说过这类是「有人拿锤子砸墙墙会不会裂」,不测。不要联网。

## 产品是什么
OpenDesign:室内设计师(产品负责人本人,不是程序员)用的 Windows 桌面 AI 助手(Electron 窗口)。
聊天要用大模型,模型来自几家厂商,每家填自己的 API Key、扣各自的钱:MiMo(小米)、DeepSeek 官方、Kimi 按量、GLM 套餐(Coding Plan)、GLM 按量,
还能「添加供应商」自己起名字。界面:左侧栏(工作区、聊天、设置…);聊天有三个地方:首页聊天、每个项目的「项目助手」栏、待办页的助手栏,
三处各聊各的。助手能干活:「记一下」(把业主的口头改动记进项目变更账本)、「整理文件夹」(扫描一个目录给出归类方案,你确认之后才动文件)、
「找参考图」(在已入库的参考图里检索)。还有一个「技能」页,列着这三个技能,点卡片会开一段新对话并在输入框里预先填好开头。

## 输入框现在的样子
- 首页空着时:大字问候「今天想聊点什么?」,下面一张大输入卡,再下面三个建议问法。
- 输入卡:文字框(占位字「聊设计、找参考,或「记一下…」」;项目助手里是「问这个项目,或「记一下…」」);
  下面一排:「+」(只能选图片;图片也能拖进来或 Ctrl+V 粘贴,最多 4 张)、「✎ 记一下」(点了只是在文字前面补「记一下:」)、
  右边是模型按钮(只写模型名,如「mimo-v2.5」,点开能换厂商和模型)和文字按钮「发送」(回复中变灰)。
- Enter 发送,Shift+Enter 换行;用中文输入法打拼音时按 Enter 是选字,不会把拼音发出去。
- 回复过程中:先有「正在思考」小动画,然后文字一段段出来;**没有办法中途停下**,只能等它说完。
- 模型出错时,聊天里会出现一条粉色的中文出错说明,下面一行小字「原文:…」。

## 要做成的样子(五条是产品负责人同意的,细节是我们定的)
1. **「+」变成一个菜单**:第一项「图片」(旁注「也可拖进来 / Ctrl+V」),下面「技能」三项:记一下 / 整理文件夹 / 找参考图。
   点技能 = 在输入框里补好这个技能的开头(记一下 →「记一下:」;整理文件夹 →「帮我扫描整理这个文件夹:」;找参考图 →「找参考图:」),
   光标停在后面等你接着打;输入框里原来已经打了字,开头补在前面、原来的字留着;原来已经是某个技能的开头,就换成新的开头,不会叠两个。
   「✎ 记一下」按钮去掉。技能页和这个菜单用同一份技能表。
2. **输入框里打 /**:输入框内容以 / 开头、后面还没有空格时,弹出同一份技能表;/ 后面接着打字会按字筛(例如「/参考」只剩找参考图);
   ↑↓ 选、Enter(或 Tab)用、Esc 关;筛不到任何技能就不弹,Enter 照常把这句发出去。占位字改成「聊设计、找参考;输入 / 选技能」。
3. **模型按钮前面带厂商名**:写成「厂商短名 · 模型名」,如「MiMo · mimo-v2.5」「GLM 按量 · glm-5.1」「DeepSeek 官方 · deepseek-v4-flash」。
   短名 = 设置页那家的名字去掉括号里的部分(MiMo(小米)→ MiMo;GLM 套餐(Coding Plan)→ GLM 套餐);自己起名的供应商照写。
4. **发送换成 ↑ 图标;回复中变成 ■ 停止**。点 ■:这次回复马上停下(包括还在「正在思考」、一个字都没出来的时候),输入框解锁可以接着发;
   已经出来的半截回答留着;聊天里出现一行灰色小字「已停止」;不会出现一条写着 “/stop” 的气泡。切走再回来、关掉重开,看到的也是中文。
   **注意**:如果停的那一刻助手正在执行一个动作(比如正在往账本里记一条、正在挪文件),这一步可能已经做完了,只是助手不再汇报 —— 这是后台现有的行为,这次不改。
5. **首页问候语按时间变**:早上好 / 中午好 / 下午好 / 晚上好 / 夜深了,后面接「,今天想聊点什么?」。
- 顺带两处小修:
  a. 出错说明的小字:有几种错误(例如某家欠费)后台给的不是厂商的原话,而是后台改写过的一句固定英文 —— 这种小字不再标「原文」,改标别的说法;真是厂商原话的仍标「原文」。
  b. 以前某些后台系统消息会以英文原样出现在聊天里(例如 “Stopped 1 task(s).”、“No active task to stop.”、“Background task completed.”),改成中文。

## 这次请特别多想三类
1. **失败路径**:停止键在各种时机按(刚发出、正在思考、正在出字、快说完、已经说完的一瞬间);停完马上再发;网络断了时按停止;出错说明出现后的按钮状态。
2. **组合场景**:两件事叠在一起(例如:三个聊天栏同时在回复、只停其中一个;菜单开着时拖图进来;打 / 时正在用中文输入法;草稿里已有图片再选技能;
   换了模型之后按钮上的字;回复中打开「+」菜单)。
3. **跨功能影响**:这次改动会碰到的别处(原来的发图、拖图、粘贴、Enter 发送、输入法选字、模型菜单、技能页、三个聊天栏、历史对话回看、出错说明)。
