# Proposal: opendesign-workbench-p2 — 主工作区 IA 照定稿重排

- Date: 2026-07-11
- Status: approved(用户拍板「就按这个来」)

## Goal

照 Claude Design 定稿 **2a 主工作区**(`handoff/`)重建前端 IA:四列工作区
(侧栏 240 / 变更记录 flex:1 / 图片+文件 290 / AI 聊天 340),变更记录成为 C 位,
聊天退居右侧陪伴列;补齐支撑所需的**只读**后端 API。

## Motivation

P1 交付后用户真机反馈:前端「差点意思」——聊天占 C 位,与「项目工作区」的产品
定调不符。用户拿设计 brief 去 Claude Design 出图,带回定稿(handoff 包,README
为实现规格)。本 track 即照稿重建,是 P1 记下的既定断点。

## Scope

- in: 四列工作区布局 + 暖纸面 token 全套(浅色)、侧栏(品牌/全局操作/历史对话/
  项目列表/设置弹层)、中央变更记录列(真数据 + 状态筛选)、图片区(真数据接
  refs-index)、聊天列照稿重排(逻辑层零改动)、新增只读 API:项目列表/项目变更/
  项目参考图 + 安全的缩略图文件服务。

## Non-goals

- 文件区真数据(D 盘目录约定未定 → 空态占位,等首装真实反馈)
- AI 回复内嵌变更记录卡片(需结构化回复协议,另 track)
- 搜索 ⌘K、日历、技能、图墙页的真功能(入口按稿画,占位)
- 深色模式适配(定稿只有浅色暖纸面;深色选项标「即将支持」)
- ds_web 任何写操作(安全基线:保持只读;「标记完成」走聊天预填交 AI)
- 切页丢对话快修(用户已明确暂缓,不混进本 track)
