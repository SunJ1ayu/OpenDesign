# 真机清单 —— 0.91.0(**这一趟把 0.89 / 0.90 欠的一起验完**)

装 `OpenDesign-Setup-0.91.0.exe`。

**为什么一趟能验三版**:0.91 的包含 0.89、0.90 的全部改动。你之前那两份清单
(0.89 的 A~G、0.90 的 A~D)不用再单独走了 —— 该看的都合到下面了。

一条一条来,**红了就停下来告诉我**,别接着往下走。
预计 15 分钟,其中 B 组是这一趟的主角。

---

## A. 先确认装的是新的(不确认这条,后面全白做)

- [ ] **A1** 打开 OpenDesign,窗口能出来。
- [ ] **A2** 浏览器开 `http://127.0.0.1:8766/api/health`,里面的 `version` 是 **0.91.0**。
      > 不是 0.91.0 就停 —— 那说明装的还是旧的,后面全白做。这一条栽过两次。

## B. 这一单修的:右上角三个按钮 + 顶上能拖(你 08-17 报的那两条)

> 你说的「拖不动」和「右上角还是没有缩小放大和退出」是**同一个病**:
> 那条 30px 的窗口栏整块没画出来。原因我找到了(pywebview 把接口注进页面的时机
> 比我以为的晚),已经改成不依赖那个时机。

- [ ] **B1** 窗口**右上角有三个按钮**:最小化 `—` / 最大化 `□` / 关闭 `×`。
      鼠标移上去有底色,移到 `×` 上是**红底白叉**。
- [ ] **B2** 按住**顶上那条空白**(三个按钮左边那一整条)拖动 —— 窗口跟着走。
- [ ] **B3** **双击**顶上那条空白 —— 最大化;再双击 —— 还原。
- [ ] **B4** 点最小化 → 缩到任务栏;从任务栏点回来 → 窗口回来。
- [ ] **B5** 点最大化 → 铺满屏幕,**但不盖住任务栏**;再点一次 → 回到原来大小。
- [ ] **B6** 点 `×` → 窗口**收进托盘**(程序没退,托盘图标还在);
      双击托盘图标 → 窗口回来。
- [ ] **B7** **拖边改大小**:上、下、左、右、左上、左下、右下 —— 七个方向都试一下。
      鼠标移到边上时指针变双箭头。**哪个方向没反应,告诉我是哪个。**
      > **右上角那个斜角不算**(见 F4):那一小块是三个按钮的地盘。
      > 想从那一带改大小:上边在按钮**左侧**拖、右边在按钮**下面**拖,都好使。
- [ ] **B8** 在界面里**选中一段文字**、拖一下滚动条 —— 不会变成"拖着整个窗口跑"。
- [ ] **B9** 点三个按钮的**最上沿那一两像素**(贴窗口顶边那条)——
      应该是按钮生效,不是变成"改大小"的双箭头。
- [ ] **B10** **双击**最小化按钮 —— 只最小化,不该顺带最大化一次。

## E. 弹窗出来的时候,三个按钮还点不点得动

> 无边框之后这三个按钮是**唯一的出口**,任何盖住它们的浮层都是死路。
> 我这边只验得了层号,盖没盖住只有你看得见。

- [ ] **E1** 让连接失败的弹窗出现(把 key 改成一个错的、保存,等它连不上)。
      弹窗还在屏幕上时:三个按钮**看得见**、点最小化**有反应**、顶上那条**还能拖**。
      (记得把 key 改回正确的。)
- [ ] **E2** 把搜索面板调出来,同样看三个按钮还点得动。
- [ ] **E3** 图墙里点开一张图放大,同样看三个按钮还点得动。

## F. 已知偏差(看一眼就行,**不是 bug,别报**)

- [ ] **F1** 把窗口拖到屏幕**最上边**让 Windows 自己贴边最大化 —— 那一种**会盖住任务栏**
      (点我们的最大化按钮则不会)。那条路是 Windows 自己接管的,不经过我的代码。
- [ ] **F2** 承 F1:贴边最大化之后,中间那个按钮的**图标可能画反**(点下去的行为是对的)。
- [ ] **F4** **右上角那个斜角改不了大小** —— 那 6 像素完全落在三个按钮底下,
      而按钮必须压在"改大小"的感应带上面(不然点关闭按钮的上沿会变成拉窗口)。
      上边和右边照样能拖(在按钮左侧 / 按钮下面)。
      > 这不是这一版弄坏的,是无边框那一版起就如此;08-17 我新加的判据第一次跑就把它
      > 量出来了(以前没有任何判据碰得到"按下去命中谁")。你要是真觉得碍事,
      > 我可以把三个按钮往里收几像素让那个角空出来 —— 代价是**最大化时把鼠标甩到
      > 屏幕右上角点关闭会落空**(那一下会变成拉窗口),所以我没自己定,等你说。
- [ ] **F3** 聊天那列的滚动条紧贴窗口右边缘,而最右 5px 是"改大小"的感应带 ⇒
      **拖那个滚动条**时可能变成拉窗口宽度。碍事的话告诉我,修法是把那列往里收几像素
      (要单独一单)。
