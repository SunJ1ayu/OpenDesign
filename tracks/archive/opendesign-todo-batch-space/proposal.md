# Proposal: opendesign-todo-batch-space

- Date: 2026-07-22
- Status: open

## Goal

用户 0.31.0 真机验收后口述的交互缺口,补齐三项(#1 日期分组已确认无 bug,不在本 track):
待办页批量改状态 + 单项目变更列时间/空间分组 + 侧栏建档标记简化成灰色。

## Motivation

把"状态流转"这类高频动作从"逐条点"降到"整批一次"(整批业主反馈处理完要逐条勾选=真实痛点);
让进到单个项目后按设计师真正会用的**空间**轴组织变更(项目维度在单项目里冗余);侧栏去噪。

## Scope

- in #2a: 待办页(按项目 / 按时间**两个视图**)批量选 + 一起改状态;走**客户端串行调既有
  `/api/changes/edit`**,零新后端写口。
- in #2c: 单项目变更列新增「按时间 / 按空间」分组切换(现状=扁平列表 + 状态筛选 pill)。
- in #3: 侧栏未建档项目去掉「建档 →」「未建档」两个标,改**只用颜色区分**(已建档正常/未建档灰),
  hover 提示保留(已在 title)。

## Non-goals

- #2b 待办页布局放宽/两栏:**等用户 Claude Design 稿,单独一轮**。
- 不新增后端端点、不动 ds_tools/ds_web 写路径核心。
- 不做跨项目批量(选择限当前视图内)。
