# Handoff: OpenDesign 主工作区(室内设计师本地工作台)

## Overview
OpenDesign 是给室内设计师用的桌面浏览器应用(中文界面、本地数据)。设计师同时服务多个业主项目,核心痛点是口头沟通的修改需求容易忘。本设计是应用的**主工作区一屏**:进入某个项目后,变更记录(核心)、参考图/文件、AI 项目助手聊天如何共存。

**最终定稿包含两个画板**:`3a 新对话`(文件最上方 `<section id="t3">`,默认首页)和 `2a 主工作区`(`<section id="t2">`,进入某个项目后)。文件最下方 `id="t1"` 一节(1a/1b/1c)是早期探索,仅作参考,不要实现。

**导航模型**:应用启动默认落在新对话页(3a);点侧栏「项目」中某一项 → 进入该项目的主工作区(2a);点「新对话」随时回到 3a。两屏共用同一个左侧栏。

## About the Design Files
本包中的 HTML 文件是**用 HTML 制作的设计参考稿**(展示预期外观与行为的原型),不是可直接搬运的生产代码。任务是:在目标代码库的现有技术栈(React / Vue / Electron / Tauri 等)中,用其既有模式和组件库**还原重建**这个设计;若尚无代码库,请自行选择最合适的桌面应用框架实现。

预览方式:把整个文件夹放在本地,直接用浏览器打开 `主工作区探索.dc.html`(需与 `support.js` 同目录)。页面是可缩放画布,最上方 3a、其次 2a 即定稿。

## Fidelity
**High-fidelity(高保真)**:颜色、字体、间距、圆角、状态均为最终意图,应按像素级还原;但其中所有**参考图/效果图用的是斜纹占位块**,实现时替换为真实缩略图。数据(项目名、变更条目)为示例数据。

## Overall Layout(2a,画板 1440×860,实际应全屏自适应)
四列横向 flex,从左到右:

1. **左侧栏** — 240px 固定,背景 `#f3f1ea`,右边框 `1px solid #e5e1d6`
2. **中央变更记录列** — `flex:1`(主内容),右边框 `1px solid #eceadf`
3. **伴随列(图片+文件)** — 290px 固定,右边框 `1px solid #eceadf`
4. **AI 项目助手聊天** — 340px 固定,背景与主区同为 `#faf9f5`(无分隔底色,靠左列边框分隔)

页面底色 `#faf9f5`,正文字色 `#2c2a26`,基础字号 13px。

## Interactions & Behavior
- 设置行点击 → 向上弹出菜单(唯一已做的交互);再点收起。展开箭头 ▾/▴ 切换。
- 变更筛选胶囊:单选切换列表过滤;「未办结」= 待确认 + 进行中。
- 变更行 hover:浮现「✓ 标记完成」;点击将状态改为已完成(记录不删除)。
- 聊天:用户说「记一下:…」→ AI 解析出内容/空间/日期,自动创建变更记录(初始状态「待确认」),回复中内嵌该记录卡片;卡片点击应滚动/高亮中央列表中的对应条目。
- 图片分段切换 参考/效果;「+N 图墙 →」进入全屏图墙页(本稿未画)。
- 侧栏项目点击切换整个工作区上下文;「新对话」回到 3a 空态页;建议实现 Cmd/Ctrl+N 新对话、Cmd/Ctrl+K 搜索(UI 不显示快捷键角标)。
- 状态色、hover 底色见上文;所有 hover 过渡建议 120–150ms ease。

## State Management
- 当前选中项目 id;变更列表(id、编号 Cn、内容、空间、日期、来源、状态);筛选状态。
- 聊天会话(按项目隔离)+ 全局独立对话历史;流式输出状态。
- 设置弹层开合;图片区 参考/效果 tab;文件搜索关键词。
- 待办提醒计数 = 所有项目未办结变更之和。

- 项目大标题:Noto Serif SC 700, 22px
- 编号/日期/快捷键/徽标:ui-monospace 等宽,9.5–12px

**其他**
- 圆角:菜单行 7px、卡片 9–11px、聊天气泡/输入卡 14px、胶囊 99px

## Assets
无外部图片资产;所有参考图/效果图为 CSS 斜纹占位(`repeating-linear-gradient`),实现时替换为用户真实图片缩略图。图标当前用 Unicode 字符(✳ ⌕ ◎ ▦ ✦ ⚙ ≡ » ↑ +)占位,建议换成统一的线性图标库(如 Lucide),视觉重量与 13px 文字匹配。字体从 Google Fonts 加载 Noto Sans SC / Noto Serif SC(本地应用建议打包字体文件)。
