# 0.98.14 真机验收

1. 更新后在「设置 → 常规」页的「软件更新」区域,看「当前状态」显示 `v0.98.14`。原来的项目、历史对话和当前模型仍在;发一句话能正常回复。
2. 首页输入框点「+」,能看到添加图片和三个技能;选「记一下」后输入框有填好的开头。清空后输入 `/`,同样能选技能;拼音候选窗打开时按回车确认输入,消息不应直接发送。
3. 发一句需要稍长回复的话,回复中按钮变「■」;点它请求停止,按钮恢复「发送」后可以再发。已完成的项目操作不会撤回,少量在途文字可能晚到。输入框右下角模型按钮能看见厂商和模型名。
4. 侧栏选「按时间」,有旧对话时点「显示更多」能继续翻。任选一条「⋯ → 置顶」,另一条「⋯ → 改名」;切成「按项目」,从托盘完全退出再打开,置顶、名字和视图仍保留。
5. 在「按项目」里,用一条未置顶且属于该项目的对话检查:点项目旁带对话图标的数字展开,点一条能回到那段接着聊。置顶对话在顶部置顶区;全被置顶的项目不显示对话数字。另开对话请助手给已有项目记一次沟通,确认项目里新增了沟通记录后,这段应出现在该项目下。仅在聊天中提及名字不算实际操作。
6. 可选:用一条不需要的测试对话试「⋯ → 删除」并确认,侧栏里消失。若实际遇到模型调用错误,聊天页应出现说明;把提示截图反馈即可,不必特意改坏自己的 Key。

任何一步不符,记录步骤与实际看到的文字。Windows 中文输入法、真实厂商超时和这次实际升级仍需要这趟真机回显。
