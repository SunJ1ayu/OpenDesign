# Proposal: opendesign-ref-images

- Date: 2026-07-02
- Status: open — **等用户答 3 个工作流问题后开工**(见下"待用户输入")

## Goal

给 OpenDesign 加参考图管理:中央图库(文件,按 风格/空间 分类)+ markdown 索引
(每图一条 `r<n>` 记录:标签/来源/文件路径/用于哪些项目/备注)+ 3 个 MCP 工具
(add_ref / find_refs / link_ref)。让"找奶油风客厅的参考"和"翡翠湾当时看的哪几张"
都变成一句话查询,复用统计白送。

## Motivation

用户 07-02 提出参考图很重要、想优先做。经典两难(跟项目放=好找 vs 按风格放=好复用)
用"母本池 + 索引 + 用于字段"解开:文件位置变次要,两种查找都靠索引成立。
过 north-star 三连问:记忆的活 ✓ / 真实场景 ✓ / PR 级走 track ✓。

## Scope

- in: `refs-index.md` 索引格式(`- [r<n>] 标签 | 来源 | 文件 | 用于 | 备注`,不删行,r<n> 锚定)
- in: `bin/ds_refs.py` 三工具,照 ds_tools.py 范式(纯核心+MCP 包装、词表校验、flock=ds_lock、oracle 测试)
- in: 图库目录约定 `refs/<风格>/<空间>/`(文件移动复用 organize 确认闸,不新开写文件能力)

## Non-goals

- 视觉自动打标(依赖大脑看图能力未验证)→ P-later,MVP 手动口头打标
- 项目 assets/ 拷贝 → 留给 P2 项目目录化时一起
- 以图搜图/相似度 → 不做
- 缩略图/看图 UI → 用系统文件管理器,不自建

2. **标签词表**:推荐"空间锁死 + 风格半开放(常用词表可扩,扩时确认)"
3. **打标方式**:推荐 MVP 聊天口头说;自动识别要先验 MiMo 看图,另立验证任务
