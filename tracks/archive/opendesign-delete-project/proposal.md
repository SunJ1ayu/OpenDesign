# Proposal: opendesign-delete-project(队列#7:回收站式删除)

- Date: 2026-07-16
- Status: open

## 背景
07-16 改名事故:助手无删除工具,"建新档案搬变更"的替代方案留下 7 对重复档案,
只能让用户手动删。队列 #7 = delete_project 工具缺失;#8 = AGENTS.md 硬规矩
(会留残局的替代方案默认不做先问)。用户 07-16 问"更新后能让助手删重复的吗"
→ 建工具,让清理走对话。

## 方案
- 新 MCP 工具 `delete_project(project)`:**回收站式**——档案移
  `projects/.trash/<name>-<ts>.md`(不真删,删错可捞回);工作区映射若指向该
  项目一并摘除(防悬空);clients/index/refs 里的 [[引用]] **只清点不改动**
  (账本语义),返回计数供助手播报。
- AGENTS.md:工具行 + 删除纪律(设计师明确要删+复述项目名确认后才调;告知
  .trash 捞回路径)+ **#8 硬规矩**(缺工具的操作,凡会留下助手清不掉的残局,
  默认不做、先讲清后果问设计师)。
- ds-web 0.20.0 → 0.21.0。

## 非目标
- 真删除/清空回收站(手动管理 .trash);删除业主档案;批量删除。
