## ZCode 是什么(agent 读其源码 `zai-org/ZCode@872ad96` 得到的事实,你读不到那个仓)

智谱开源的 Electron 41 桌面应用。Windows 主窗口 `frame:false` 且不关 `thickFrame`(系统缩放边/贴边/最小化动画由 Electron 保住),
三个按钮页面自绘、经 preload IPC 调 `win.minimize()/maximize()/close()`,拖动区用 CSS `app-region`;
窗口 `resized` / 从托盘 `show` 后调 `webContents.invalidate()` 补两次重绘(它遇到过「窗口只剩底色」);
右键复制粘贴用原生菜单补;`setWindowOpenHandler` 把外链交给系统浏览器;`app.requestSingleInstanceLock()`;
主进程之外另 `utilityProcess.fork` 一个 host 进程跑后台;安装包 electron-builder NSIS(`oneClick:false`、可选目录);
更新 electron-updater(自定义清单 provider),`quitAndInstall` 前先等 host/子进程退完(注释:否则装机时文件仍被占用)。

## 现在的行为(均可在仓库里核)

- **外壳**:`bin/ds_shell.py`(1409 行)+ `bin/ds_shell_core.py`(1307 行,`tests/test_ds_shell_core.py` 等锁着)。
  pywebview 6.2.1(WinForms + WebView2,经 pythonnet)+ pystray。做的事:单实例锁(TCP 端口,兼作 ds-web 回呼外壳的通道:
  存 key 后请求重启网关、更新交棒)、挑端口、改写 nanobot 配置、`start_backend` 起两条后台腿(网关 nanobot + 工作台 ds-web)、
  子进程放进 KILL_ON_JOB_CLOSE 的 Job、看门狗(后台死了弹中文框)、关窗收托盘、首帧看门与诊断导出、
  frameless 窗口 + 用 ctypes 贴样式位/接管 `WM_NCCALCSIZE` 把缩放边与动画补回来(`WindowApi`)。
- **前端**:React 18 + Vite(`web/src`,dist 进仓),由 ds-web 在 `http://127.0.0.1:<端口>/?shell=1` 提供。
  和外壳的接口只有两处:`web/src/workspace/WindowChrome.tsx`(自绘三按钮/拖动带/八个缩放把手,调 `window.pywebview.api`)
  和 `web/src/startupReport.ts`(首帧/前端报错上报)。其余全是 HTTP 到 ds-web。
  前端用 localStorage 存:项目↔对话 id 映射、自动更新开关、图库列数(`App.tsx`、`GalleryPage.tsx`)。
- **安装包**:`installer/OpenDesign.nsi` + `installer/build-installer.sh`,**在 Linux 上用 makensis 编**,约 45MB;
  每用户安装,默认 `%LOCALAPPDATA%\Programs\OpenDesign`,`InstallDirRegKey HKCU Software\OpenDesign`;
  资料在安装目录外 `%LOCALAPPDATA%\OpenDesign`(卸载默认不删,删要勾一个默认不勾的选项);
  启动器 `OpenDesign.exe` 是 NSIS 编的小壳(`installer/launcher.nsi`),拉起 `python\pythonw.exe ds\bin\ds_shell.py`;
  带 WebView2 引导程序;开机自启写 HKCU Run;内含免装 Python(embeddable)约 160MB 解压后。
- **更新**:`bin/ds_update.py`(查 GitHub:先 `releases.atom` + 每版随包清单 `OpenDesign-update.json`,再退到 API ——
  业主开商用 VPN,API 未登录限流 60 次/小时/出口 IP 已真实咬过;**本仓所有 release 都是 prerelease**)、
  `bin/ds_update_apply.py`(下载 → 核 sha256 → 静默装进 `<安装目录>.new` → 接力 .cmd 收摊后两次改名 → 起新版问 /api/health;
  **09-08 否掉了「就地覆盖」**:程序还在跑时 RMDir 删不掉会静默跳过,装到一半一半新一半旧)、
  `bin/ds_update_startup.py` + `bin/ds_auto_update.py`(打开软件时只读盘:有已下好且校验过的新包就装,否则立刻进工作区;
  查更新与下载在进入工作区之后后台做)。旧版的更新器按 `OpenDesign-Setup-<版本>.exe` 认资产。
- **验证通道**:本机是 Linux(2G 内存、剩约 4G 盘),**跑不了 Windows**;仓库公开,GitHub Actions windows-latest 免费,
  已有 `.github/workflows/windows-package-probe.yml`(下真安装包→静默装→启动→截图→收日志)与
  `windows-update-e2e.yml`(替身 GitHub 上跑真更新)。动画/手感只有业主真机能验。
- **历史**:这一年窗口层三次白跑业主真机(0.89 开机崩、0.90 窗口栏整块没画出来、0.93 打开全白);
  「pywebview 注入 api 的时机」栽过四次;08-25 一次白屏根因至今未定(WebView2 换版嫌疑未排除)。
- 版本号只许加第三位(下一版 0.98.10),1.0 留给业主。

## 约束

- key 原文永不进配置、永不回显给浏览器;资料根不许被安装/更新/卸载误删。
- 业主不是程序员:任何要他理解「进程/端口/重启/注册表」的步骤都是成本;他能做的是下载、双击、点按钮、看一眼截图。
- 装好的应用是主路径;git-pull 部署与 Linux 开发机(浏览器直接开 ds-web)不能被弄坏。
- 外部执行腿不许联网、不许装依赖;构建与 Windows 验证可以放在 GitHub Actions。

## 拟改变的、用户看得见的行为

- 窗口换成 Electron,样子照旧:顶上是我们自己的界面,右上角三个按钮我们画;缩小放大有动画、能贴边分屏、能拖边缘改大小。
- 关窗收进托盘、托盘退出才真退出、再双击图标把窗口叫出来 —— 与现在一致。
- 安装包换成 electron-builder 做的,照样能选安装位置、资料放在安装目录外。
- 自动更新换成 electron-updater;「打开软件不被更新卡住」保留。
- 换壳这一版业主手动装一次(卸旧装新),之后回到自动更新。
