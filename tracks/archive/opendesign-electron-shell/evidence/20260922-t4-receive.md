## 发现与处置

| # | 发现 | 性质 | 处置 |
|---|---|---|---|
| F1 | 起不来的三种(fatal / already-running / 版本对不上):弹框后窗口停在转圈的「正在启动…」,加载页整页拖动带、没按钮;旧版 `die()` 是弹框后退出 | **我的规格洞**(design 没写弹框之后怎样) | 补 mc19 / mc20(护栏:能接着用的不退)+ c10g(quitApp 走 quitAll);design 接缝表加 `quitApp` |
| F2 | 管家 spawn 没接 `error`(python.exe 缺失 / 被杀软隔离 ⇒ 主进程未捕获异常、英文堆栈);同类再扫:stdin 的 EPIPE 同样没人接 | 我的规格洞 + 腿的健壮性 | 补 mc21 + c10f;design 加 `hostError` |
| F3 | 桌面形态平时没有「检查更新」(只在出错时有「重试」);旧版一直有,design D 写的是「改接」+ `update.check()` 手动查 | **我的任务书**写成「旧的查更新…全部删掉」 | e2e desktop_update 加 A(idle/latest 在、其余不在)/ D(点了只叫 check)/ C(浏览器没有) |
| F4 | 查不动时说「没查到更新,请稍后重试」—— 业主读成「没有新版」(du4b 自己就写着这个理由) | 我 du4 放行了「没查到」 | du4 收紧:要「失败 / 没成功 / 连不上」、不许「没查到 / 查不到」(云 E4 认 `/没查到\|查不到\|失败/`,不冲突) |
| F5 | 下载好之后打开设置:弹层里的「重启以更新」盖住「设置」那一行,点不到(e2e `desktop_update` A downloaded / B 红);`.settings-pop` 写死 `bottom:54px`,那一行加了按钮后高 96px | **腿的真 bug**,T3 判据抓到 | 不需新判据;复现:Playwright 报 `settings-pop … intercepts pointer events` |
| F6 | 死断言 `wait_event` 超时分支 | 我的判据 | 改成语句位每次真跑的 `assertIsNotNone`(b8 同款,不进放行清单);另验等不到就红 |
